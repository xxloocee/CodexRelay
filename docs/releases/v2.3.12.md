# CodexRelay v2.3.12

本版本针对 [Issue #4](https://github.com/xxloocee/CodexRelay/issues/4) 提供最小、可选的 WSL2 监听兼容增强，由用户手动配置 WSL2 客户端。

## 调整

- “设置 > 网络 > 允许 WSL2 访问”默认关闭，仅监听 `127.0.0.1`；开启后监听 `0.0.0.0`，所有请求仍需携带本地访问令牌。该范围也允许其他可达设备连接，防火墙由用户自行配置。
- WSL2 NAT 用户可手动将客户端地址设为 `http://<Windows主机IP>:<端口>/codex`，并配置 Relay 的本地访问令牌；其他类别使用对应路径。不会自动发现 WSL2、修改防火墙或自动配置 WSL2 客户端。
- Windows 展示、复制和自动写入的 Relay 地址始终使用 `127.0.0.1`，客户端自动配置、切回官方及故障切换继续沿用原规则。
- 开启或关闭开关只切换监听范围，不改写客户端文件；关闭后恢复回环监听，不撤销用户手动配置。切换监听可能有短暂连接间隙，已在处理的请求采用异步优雅关闭。
- 精简客户端访问主机设置及相关校验，避免将 WSL2 配置扩展为全局客户端模式。绑定或保存失败时尝试恢复原监听，失败信息明确返回。
