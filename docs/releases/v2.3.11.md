# CodexRelay v2.3.11

本版本修复 Codex 配置切换后官方地址和密钥模式不能稳定生效的问题，并完善二狗子账户密钥删除流程。

## 修复与调整

- Codex Relay 配置同时覆盖根级 OpenAI 请求地址和自定义 Provider，切回官方配置时清理冲突覆盖项，并保留原生认证来源。
- Codex 切换后的诊断会区分配置已写入、等待请求验证和已观察到请求，避免把文件写成功误报为请求已生效。
- 二狗子账户密钥删除前核对当前账户返回的完整密钥；服务地址、绑定凭据或同一远端 ID 对应密钥变化后，旧本地身份失效，避免误删其他账户的密钥。
- 删除核验和删除请求不跟随 HTTP 重定向，远端拒绝、身份不匹配或结果未知时保留本地记录。
- 更换二狗子服务地址会清除旧服务的本地令牌目录、配置和切换提示；同步后需重新导入密钥，远端密钥不会被删除。
- 删除或失效账户密钥后清理相关启用映射、故障切换状态、健康记录和运行时提示，并避免在账户锁内触发健康回调。

## 下载与验证范围

GitHub Actions 将为 Windows、macOS、Linux 的 x64/ARM64 构建六个安装包，并提供 Windows 应用内更新包和 `SHA256SUMS`。安装包未签名或公证；Linux 需要系统提供 `libwebkitgtk-6.0`。

本次独立合成接口验证覆盖账户身份核验、五类 HTTP 重定向、服务/绑定切换、同 ID 密钥变化、失效提示清理和锁外回调。未执行真实账户删除、真实 Codex 请求、全量本地构建或各平台实机验证。
