# CodexRelay v2.3.9

本次更新增强 Codex 官方账号/API 切换，并新增不区分原供应商的历史会话修复。

## 新增

- 设置 → 高级 → Codex 新增“修复历史会话”：将各供应商、空值及缺失 Provider 的本机主会话统一归入 Codex 当前选中的 Provider，自动备份，无需逐个选择供应商。
- 同步会话文件与本地索引；对仍有主索引及真实会话文件的记录，补全支持的桌面目录项并清除错误隐藏标记。
- 新增脱敏切换诊断日志，区分配置校验通过与请求实际进入 Relay；支持识别有效的 `CODEX_HOME`，显示配置目录来源。

## 修复

- 官方/API 切换时保持 Provider 和认证配置唯一，清理 profile 中的连接覆盖，核对名称、Base URL、Responses 协议及认证标记；Provider 选择字段固定写在配置顶部。
- 跳过配置替换时仍检查 Codex Relay 配置，避免界面显示切换成功但客户端继续请求旧地址。
- 切回官方时保留最新 MCP、插件、项目和界面设置；切换时清理不属于当前上游的模型配置残留。
- 历史修复不再因合法官方 OAuth 的空 API Key 或 Relay 保存状态而被拒绝。
- 历史备份恢复支持文件部分改写、数据库尚未提交及重复恢复；进程退出后自动释放修复锁，外部修改仍会被保护。
- 历史预览和修复改为按文件处理，避免全部历史正文同时占用内存；数据目录迁移时保留历史修复备份。

## 使用说明与验证范围

修复前请完全退出 Codex 桌面版、CLI 和 IDE 内的 Codex 进程。修复后重新打开 Codex；以后切换到其他 Provider，若历史再次不可见，可再次修复。归档状态保留，内部子任务及远程设备记录不会加入普通主列表。

完全丢失的会话文件或主索引、外置数据库、跨账号/供应商的加密续聊不在恢复保证内。单个超大会话文件仍需要相应内存。

发布准备阶段的相关后端合成回归和独立源码审查已通过；未操作真实用户历史，未进行 Codex 界面恢复或各平台实机验证。构建结果以本版本 GitHub Actions 为准。Windows 自动更新可用；macOS/Linux 使用下列安装包更新，不提供应用内开机自启动配置，系统代理读取环境变量。安装包未提供代码签名/公证。
