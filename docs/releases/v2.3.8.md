# CodexRelay v2.3.8

本次更新修复客户端配置写入与官方账号/API 切换问题。

## 修复

- 修复 Windows 数据目录与客户端配置目录位于不同盘符时，配置操作失败的问题。
- 配置、切换 API 和恢复官方配置时，允许覆盖操作前的外部修改，不再因旧文件指纹不一致而拒绝写入；保留官方备份完整性校验和失败回退。
- 修复 Codex `auth.json` 损坏时无法重新配置的问题。
- 修复 TOML 顶层字段缩进和 provider 段尾注释导致的字段处理错误及重复段问题。
- 保留官方账号登录配置，支持官方账号与 Relay API 往返切换；外部重新官方登录后再次接管时，保存最新登录信息。

## 调整

- Codex 官方入口改名为“OpenAI官方”，描述新增“可保留账号登录态”。
- 同步配置覆盖行为的回归测试，补充账号/API 往返、外部修改、认证文件损坏或缺失、重新登录及失败回退的验证。

## 下载说明

- Windows：x64、ARM64 安装包及独立 EXE。
- macOS：Intel x64、Apple Silicon ARM64 DMG。
- Linux：AMD64、ARM64 DEB，需系统提供 `libwebkitgtk-6.0`。
- 共 8 个程序附件，附 `SHA256SUMS` 校验清单；全部为 64 位。

登录态保留依赖接管前存在可备份的官方登录配置；凭据过期或被撤销时仍可能需要重新登录。
